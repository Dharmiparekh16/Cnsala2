Computer Virus

[ Host-Bound Parasitic Vector ]

Attaches malicious instructions to clean host executables and documents. Requires human file transfer, shared SMB storage, or USB media to traverse from one endpoint to another.

Replication: Host Executable Insertion
Propagation: User Document Transfer
Latency: User / Hop Dependent

Class 02

Network Worm

[ Autonomous Self-Replicator ]

Standalone self-contained program that self-replicates laterally across computer subnets. Actively probes network ports, weaponizes unpatched service flaws (SMB/RDP), and spreads without user action.

Replication: Autonomous Cloning
Propagation: Lateral Port Exploit Sweeps
Latency: Instant / Exponential

Class 03

Trojan Horse

[ Disguised Backdoor & C2 RAT ]

Masquerades as legitimate software (utility, installer, document). Does not self-replicate laterally! Delivered via web drops or phishing to install backdoors and beacon to external Command & Control.

Replication: Non-Replicating (Carrier Trap)
Propagation: External Dropper / Ingress
Latency: Stealth Ingress / Reverse C2
